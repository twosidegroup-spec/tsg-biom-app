# TSG BIOM — native builds (Capacitor)

The same codebase that serves the live web app wraps into native
Android and iOS apps with Capacitor. Config lives in
`capacitor.config.json` (appId `com.twosidegroup.biom`) and
`package.json` (`@capacitor/core`, `@capacitor/cli`,
`@capacitor/android`, `@capacitor/ios`).

## Steps

1. `npm install`
2. `npm run stage` — copies the runtime web files into `www/`
   (Capacitor requires webDir to be a real folder; the live site is
   served from the repo root, so `stage-www.js` bridges the two).
3. `npx cap add android` (and `npx cap add ios` on a Mac)
4. `npm run cap:sync` after every web change (re-stages, then syncs)
5. Android: `npx cap open android` → build the APK/AAB in Android
   Studio or with Gradle. iOS: `npx cap open ios` → Xcode archive.

Verified 2026-11-20: `cap add android` + `cap sync android` complete
cleanly and the Android project's assets contain exactly the app
files (index.html, app.js, biometrics.js, styles.css, sw.js).

## Honest limits

- The `android/` and `ios/` platform folders are generated by step 3
  and are git-ignored, not committed. `www/` is likewise generated.
- iOS builds require macOS + Xcode. They cannot be produced on a
  Linux machine.
- Camera inside the native shell uses the same getUserMedia pipeline
  (WKWebView / Android WebView both support it over the app's secure
  context); the v21 capture tuning (continuous focus/exposure where
  the platform exposes it) applies unchanged.
